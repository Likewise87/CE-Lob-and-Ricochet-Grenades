# CE Lob and Ricochet Grenades

RimWorld mod for Combat Extended: choose grenade throw angle (Normal / lob / ricochet), bank off walls (up to 3 bounces), and preview the path.

**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3793459785

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- [Combat Extended](https://steamcommunity.com/sharedfiles/filedetails/?id=2890901044)

## Build

```bash
dotnet build Source/CE_LaR_Grenades.csproj -c Release
```

Output: `Assemblies/CE_LaR_Grenades.dll`
